# spyc

A terminal viewer for browsing code bases. It finds the project you point it at, shows the files as a tree,
colors the code, and is meant to be the tool you open a code base with.

## Requirements

- Python 3.11 or later
- `git` on the path

## Usage

```sh
pip install .
spyc [PATH[:LINE]]
```
